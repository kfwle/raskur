# Raskur

Автораскур для современных прокси-протоколов.

**Raskur** автоматически устанавливает, настраивает и запускает серверы для:

* **TUIC**
* **AnyTLS**
* **Miery**
* **Juicity**

Проект рассчитан на быстрое развёртывание прокси-сервера на Linux VPS без необходимости вручную создавать конфигурации и systemd-сервисы.

## Установка

```bash
curl -fsSL https://raw.githubusercontent.com/kfwle/raskur/main/install.sh | sudo bash
```

После установки необходимые компоненты и сервисы будут настроены автоматически.

## Удаление

```bash
curl -fsSL https://raw.githubusercontent.com/kfwle/raskur/main/uninstall.sh | sudo bash
```

## Поддерживаемые протоколы

| Протокол    | Транспорт  | Особенности                          |
| ----------- | ---------- | ------------------------------------ |
| **TUIC**    | QUIC / UDP | Современный UDP-протокол с TLS       |
| **AnyTLS**  | TCP        | TLS-транспорт с мультиплексированием |
| **Miery**   | UDP* & TCP | Современный лёгкий прокси-протокол   |
| **Juicity** | UDP        | QUIC-based прокси                    |

## Что делает Raskur

Raskur автоматизирует типичные действия при развёртывании прокси:

* установку необходимых компонентов;
* генерацию конфигурации;
* настройку пользователей и UUID;
* создание systemd-сервисов;
* запуск и остановку сервисов;
* настройку TLS;
* получение параметров подключения;
* удаление установленной конфигурации.

Вместо ручного создания конфигов и сервисов достаточно запустить установщик.

## Требования

* Linux VPS
* `root` или `sudo`
* systemd
* доступ в интернет
* открытые порты для используемых протоколов

## Важно

Raskur — инструмент для автоматизации развёртывания прокси-серверов. Перед использованием убедитесь, что эксплуатация соответствующего сервиса и протокола разрешена в вашей сети и юрисдикции.
